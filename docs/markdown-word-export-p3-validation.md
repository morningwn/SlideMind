## 4. 人工验收样本要求

同一份样本至少包含：六级标题、中英文混排、从 3 开始的有序列表、三层嵌套列表、任务列表、窄表与超宽表、跨页长列表、长行代码块、HTTP/邮件/文档内链接、PNG/JPEG 及 Mermaid 代码块。每个平台保留以下证据：

1. 安装包文件名、字节数和 SHA-256。
2. 安装目录字节数及 Pandoc、参考文档、许可证和对应源码归档的位置。
3. 断网导出结果、应用版本、操作系统与 Word 版本。
4. Word 中各验收点截图，以及发现的问题、严重级别和是否阻断发布。
5. 导出 DOCX 的字节数与 SHA-256；不要提交包含隐私内容的测试文档。

在三目标运行门禁与两平台 Word 视觉门禁完成前，P3 保持“进行中”。
