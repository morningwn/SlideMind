# PPTist 模板语义

本参考提炼自 PPTist 官方 `doc/AIPPT.md`。模板并非专用文件格式，而是标注了页面类型和节点角色的普通 PPTist 页面；模板数据也可作为普通页面模板使用。

## 页面类型

| `slide.type` | 页面职责 | 应匹配的内容 |
| --- | --- | --- |
| `cover` | 封面 | 标题、可选正文、背景图或页面插图 |
| `contents` | 目录 | 章节列表；项目数应与节点容量匹配 |
| `transition` | 章节过渡 | 章节标题、可选正文和章节编号 |
| `content` | 内容 | 页面标题，以及一个或多个内容项 |
| `end` | 结束/致谢 | 简短结束语和可选图片 |

## 文本节点角色

文本节点使用 `element.textType`；带文字的形状使用 `element.text.type`。常见角色：

- `title`：页面或章节标题；
- `subtitle`：副标题；
- `content`：页面级正文；
- `itemTitle`：内容项标题；
- `item`：目录项或内容项正文；
- `itemNumber`：内容项编号；
- `partNumber`：章节编号；
- `header`、`footer`、`notes`：页眉、页脚和辅助说明。

替换文字时保留目标节点的几何、字号层级、颜色和对齐意图。模板节点没有对应内容时可以移除；不能把占位文字留在成品中。

## 图片节点角色

图片节点使用 `element.imageType`：

- `background`：背景图；
- `pageFigure`：页面级主插图；
- `itemFigure`：与单个内容项对应的插图。

图片标记只适用于图片节点。模板资产中的 `source` 是离线占位图，仅用于表达图片区域；没有用户提供的内嵌图片时，应移除占位图，或用形状与留白重构该区域。

## 页面匹配

1. 先按页面职责筛选 `slide.type`。
2. 对目录页统计 `item` 节点数；对内容页统计 `itemTitle`、`item` 和 `itemNumber` 的成组容量。
3. 优先选择容量等于内容项数的页面；没有精确匹配时，选择能够容纳内容的最小页面。
4. 单项内容可选择没有 `item` 节点、但包含一个 `title` 和一个 `content` 的普通内容布局。
5. 如果候选页容量仍不足，拆分内容页。PPTist 原始 AIPPT 可以拼接或裁减模板，但 `slides_write` 没有该自动逻辑，不能通过缩小字号硬塞。
6. 多个同等候选页中，根据图片需求、文字长度和前后页构图变化选择，不随机选择。

模板库无需把所有候选页面写入最终演示。官方建议大量候选页是为了生成时的适配和变化，不代表成品应达到相同页数。

页面类型、节点角色和容量规则已经从 PPTist 模板式 AIPPT 说明提炼并完整保存在本文件中，执行时不读取外部文档。
