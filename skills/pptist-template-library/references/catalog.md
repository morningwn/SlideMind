## 选择规则

- 用户指定模板名称或明确配色时，优先服从用户选择。
- 正式程度高且需要稳重感时，优先考虑山河映红或深邃沉稳。
- 科技、商业和结构化分析优先考虑都市蓝调或智感几何。
- 内容强调亲和、文化或生活方式时，优先考虑柔光莫兰迪或浅蓝小清新。
- 环保、健康和自然主题优先考虑简约绿意；历史与传统文化优先考虑暖色复古。
- 品牌规范与模板冲突时，以用户提供的品牌规范为准，只借用模板布局。

## 资产

每个 ID 对应 `assets/<ID>.json`，其中包含：

- `theme`：主题色、默认字体、背景、阴影和轮廓；
- `slides`：完整候选页面；
- `slides[].type`：`cover`、`contents`、`transition`、`content` 或 `end`；
- `slides[].elements`：PPTist 原始元素结构。

页面选择不要只看类型；继续按 [template-semantics.md](template-semantics.md) 的节点容量规则筛选。
