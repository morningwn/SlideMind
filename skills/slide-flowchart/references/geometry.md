# 流程图几何配方

## 安全区与尺寸

默认 1000 × 562.5 画布使用以下基线；画布不同时按宽高比例缩放：

- 页标题区：`x = 64..936`，`y = 40..112`；
- 流程安全区：`x = 72..928`，`y = 144..506`；
- 普通节点：宽 `168..210`，高 `64..84`；
- 节点最小间隔：水平 `48`，垂直 `36`；
- 节点正文：`18..22px`，最多两行，每行建议不超过 12 个汉字或 24 个拉丁字符；
- 连线：`2..3px`；次级/异常路径可用 `dashed`。

## 锚点

对于节点 `{ x, y, width, height }`，只使用边界中点作为连线锚点：

- 左：`(x, y + height / 2)`
- 右：`(x + width, y + height / 2)`
- 上：`(x + width / 2, y)`
- 下：`(x + width / 2, y + height)`

水平主流程使用前一节点的右锚点到后一节点的左锚点。垂直主流程使用下锚点到上锚点。箭头终点不要超出边界；由于连线先于节点写入，端点的少量视觉重叠会被节点覆盖。

## 四步水平流程

在安全区中使用 `width = 178`、`height = 76`、`y = 246`，节点 x 依次为 `72, 298, 524, 750`。连线端点为：

```json
{
  "type": "line",
  "x1": 250,
  "y1": 284,
  "x2": 298,
  "y2": 284,
  "endMarker": "arrow"
}
```

先写入三条连线，再写入四个节点。当文字超过两行时增大节点高度并保持中心 y 一致，不单独移动某条连线。

## 分支与正交路由

分支节点与目标节点不在同一行或同一列时，使用 `routing: "orthogonal"`。工具会根据两端的主偏移方向选择水平先行或垂直先行：

```json
{
  "type": "line",
  "x1": 500,
  "y1": 278,
  "x2": 720,
  "y2": 390,
  "routing": "orthogonal",
  "style": "solid",
  "endMarker": "arrow"
}
```

一个源节点连接多个目标时，优先分别创建连线。只有分岔过密时才创建无箭头的共享主干，并从主干分别连向目标；每个目标线保留自己的箭头。

## 几何复核

从 `slides_read` 的返回值计算，不靠目测：

- 普通元素边界为 `[x, x + width] × [y, y + height]`；
- 线条使用 `(x1, y1)` 和 `(x2, y2)`；
- 除了线条贴合的源/目标节点，线段不应穿过其他节点的矩形区域；
- 同一行节点的中心 y 差不超过 2px，同一列的中心 x 差不超过 2px；
- 页标题与流程安全区不重叠。
